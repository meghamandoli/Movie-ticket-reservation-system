## 📌 **About the Project**

The **Movie Ticket Reservation System** is a console-based C++ application that simulates the complete process of movie ticket booking in a cinema. 
The system is designed to manage movies, screens, shows, seats, customers, bookings, and payments in a structured and modular way. 
A customer can select a movie and show, check the available seats, choose preferred seats, and get the total ticket price based on the selected seat type. 
The system provides **UPI, Card, and Cash** payment options and confirms the booking only after successful payment. 
It also allows users to cancel bookings, automatically release the booked seats, and handles invalid inputs and unavailable seats to maintain a smooth and reliable booking process. 
The project demonstrates the practical use of **Object-Oriented Programming and modular system design in C++**.

## ✨ **Features**

- 🎥 View available movies and shows
- 💺 Check and select available seats
- 🎟️ Book movie tickets
- 💰 Calculate ticket price based on seat type
- 💳 Payment through **UPI, Card, or Cash**
- 🧾 Generate and display ticket details
- ❌ Cancel bookings and release seats
- ⚠️ Handle invalid inputs and unavailable seats
